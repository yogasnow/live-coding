# Live Coding · музыкальные эскизы

## Мелодия в коде

[Чистовая карточка в чёрно-зелёном стиле](cards/melody-matrix-release.png) показывает первый такт из [16-тактового TypeScript-кода, присланного Снежаной](melody/snezhana-melody.ts). [Первый мотив отдельным файлом](melody/opening-motif.ts) удобен для дальнейших вариаций. Полный код создаёт события мелодии, аккордов и баса; проверено исполнение через Node.js 24 с `--experimental-strip-types` — 16 тактов, 64 доли, без ошибок проверки размера.

Фрагмент рукописного нотного листа на карточке — визуальный источник Снежаны. Точное соответствие каждой ноты на фото и в присланном коде **не подтверждено**; код не следует называть нотной транскрипцией фотографии.

Открытый рабочий репозиторий для музыкального live coding. Первая подборка — варианты партитуры на Strudel: [16 тактов](strudel/dj-luv-16-bars-strudel.txt), 64 и 128 тактов (полные и упрощённые версии), плюс [визуальная карточка](visuals/strudel_handwritten_melody_code.png) о переводе мелодии в код.

## Как попробовать

Открой [Strudel](https://strudel.cc/), вставь содержимое одного файла из `strudel/` в редактор и запусти воспроизведение. Регулируй громкость перед запуском.

**Статус:** рабочие музыкальные эскизы, а не подтверждённая запись живого выступления или готовый релиз. Файлы фиксируют версии аранжировки; связь с авторским рукописным оригиналом и роли участников будут описаны после сверки.

Публикация не означает разрешения на повторное использование мелодии, кода или иллюстрации: лицензия пока не указана. Происхождение рукописного оригинала и роли участников ещё сверяются.
