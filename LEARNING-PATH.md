# Как читать Live Coding

Этот короткий маршрут помогает перейти от музыкальной карточки к коду, даже если TypeScript пока незнаком.

## 1. Нота и длительность

`pitch: "C4"` называет высоту звука: в научной записи это среднее до (до первой октавы в русской традиции). `beats: 1` означает одну долю; `0.5` — половину доли. Мелодия — последовательность таких нот.

## 2. Такт и размер

Каждый объект `Bar` хранит размер (`meter`), аккорд (`chord`), звуки гармонии, бас и мелодию. В размере 4/4 на мелодию отведено четыре доли, в 3/4 — три, в 5/4 — пять. Код проверяет сумму длительностей и сообщает об ошибке, если такт не заполнен точно.

## 3. Три слоя

- **Melody:** ноты звучат по очереди; у каждой есть начало `startBeat` и длительность `beats`.
- **Chords:** звуки гармонии начинаются вместе и в этой версии длятся весь такт.
- **Bass:** основной звук и квинта чередуются по долям.

В 16 тактах получаются разные группы: первые шесть — 4/4, затем два такта 3/4, затем два такта 4/4, два такта 5/4 и заключительные четыре такта 4/4. Всего **64 доли**.

## 4. Что делает программа

TypeScript переводит партитуру в список событий. Событие описывает *какой слой*, *какую ноту*, *когда начать* и *как долго держать*. Проверка и список событий уже работают. Генерация звука — отдельный следующий шаг: текущий файл не является аудиозаписью.

## Попробуй сама

Найди первый такт в [исходнике](scores/2026-10-26-melody-presentation.ts). Мелодия `C4 → D4 → E4 → D4` длится `1 + 0.5 + 0.5 + 2 = 4` доли. Измени одну высоту ноты, не меняя длительность: структура такта сохранится, а мелодический рисунок станет другим.
